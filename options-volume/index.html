口径与免责声明

  • 期权总成交量 = Cboe 延迟分时 total_options_volume 的合计。看涨、看跌用同一文件里的 calls_volume / puts_volume。分时是增量，不是累计线。同一时刻把期权链逐合约加总，和这个合计很接近。
  • 看涨 % / 看跌 % = 该侧成交量 / （看涨 + 看跌）。百分比保留两位，看跌用 100 减去看涨，所以两侧相加是 100。
  • IV30 = Cboe 延迟报价里的 iv30。IV30变化 = 同一对象的 iv30_change（Cboe 公布的相对前收变化）。指数和部分 ETF 收盘后这个变化可能是 0，页面照实写 0，不另造一个变化。
  • 排名只在固定观察池里进行。观察池写在 options-volume/scripts/universe.py，来自 2026-10-19 Zen Research 日报的 20 个标的（SPY、QQQ、SPX、IWM 以及当日表上的大票）。
  • 更新：工作日 21:30 UTC（北京时间次日 05:30）的 Action 重写 data/latest.json。夏令时这是美东 17:30，冬令时是美东 16:30。页头「手动刷新」打开该工作流，需要仓库写入权限后再点 Run workflow。

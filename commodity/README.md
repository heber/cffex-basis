# 中国商品期货贴水跟踪

跟踪 SHFE / DCE / CZCE / INE / GFEX 主要活跃商品的**近月代理现货**、**主力连续**、活跃期限结构和近 3 年分位。

## 主力是什么

每个品种**只有一条**连续序列，叫主力。某个交易日它等于当时最活跃的那一张合约（持仓加成交最高），不是近月，也不是另挂一条「交易所主力」。

```
得分 = 持仓量 + 成交量
主力 = 得分最高的未到期合约
```

得分相同：持仓量更高者优先，其次成交量，再次更近的到期月。

领先合约换手的那天，序列换到新合约上，并用比率拼接去掉换月缺口。页面上写的合约代码就是这条序列**当天的腿**。

## 现货是近月代理

页面上的现货不是港口价、品牌价或厂库现金价。那些报价往往不是交割品（铁矿的品牌和干湿吨、厂库升贴水），拿来减期货会假装精确，所以这里不用。

现货是当天该品种**未到期合约里到期最早的一张**，用来代理现货。到期日当天仍算未到期。没有成交也没有持仓的合约不算。

```
现货代理 = 未到期合约中到期日最早者
并列     = 得分（持仓 + 成交）更高，再比持仓，再比成交
```

它常常比主力更近月。主力仍是持仓加成交最高的那条连续序列，不改叫现货。

## 次活跃远月，不是相邻月

对照腿是到期**晚于**主力、且得分最高的合约。豆粕常见 1 月对 5 月，而不是对紧邻的 3 月。曲线表里其余行是得分靠前的活跃月份，用来看期限结构，不代表第二条主力。

年化贴水的远腿固定用这一张，不另选「比现货更远」的月份。没有更远的活跃月份，或者这张远月的到期日不晚于现货代理时，年化贴水为空。

## 贴水怎么定义

```
价差     = 现货代理价 − 次活跃远月价
年化贴水 = 价差 / 现货代理价 × 365 / (次活跃远月到期日 − 现货代理到期日)
```

- 正数 = 贴水（backwardation，近高远低）。远月比近月代理更便宜。
- 负数 = 升水（contango）。远月更贵。
- 年化只用自然日 365，不扣利率，不用 252。
- 两个到期日相距不足 7 个自然日时不年化。
- 历史日线用结算价（结算为 0 时用收盘），并按上面的公式重算每日年化贴水。页面曲线用最新价。
- 价格分位仍用比率拼接后的主力价，不改用现货代理。

到期日是工作日近似，**没有剔除法定节假日**（长假附近会差几天）：

| 规则 | 品种 |
|------|------|
| 合约月 15 日，遇周末顺延到周一 | 上期所螺纹、热卷、铜、铝、锌、镍、黄金、白银 |
| 交割月前一月的最后一个工作日 | 原油、燃料油、低硫燃料油 |
| 合约月第 10 个工作日 | 大商所、郑商所、广期所品种 |

## 两个分位

格子里只写百分数（`72%`）。样本不足 30 个交易日显示「—」。悬停可看样本数。

窗口都是行情日往前 3 个日历年，**含起始日、不含行情日当天**。

### 贴水分位

同一品种上，按现货代理对次活跃远月算出的年化贴水 ≤ 今天的交易日占比。

**分位越高，远月折价越深**（比这段历史里更多的日子更贴水）。分位越低，贴水更浅或已经升水。

### 价格分位

比率后复权的主力价格 ≤ 今天可交易价的占比。拼接锚定在今天：最后一个点就是主力的现价，换月缺口不算进涨跌。

**分位越高，价格越接近近 3 年高位。** 这是价格位置，不是贴水。

## 乘数、面值和最低保证金

```
面值       = 最新价 × 合约乘数
最低保证金 = 面值 × 交易所普通月份最低投机保证金比例
```

总览的面值和保证金用**主力**最新价。详情里现货代理、主力、次活跃远月各自用自己的最新价。金额是人民币。原油 `sc` 在能源中心的报价单位是**元/桶**，不是美元；低硫燃料油 `lu` 仍是元/吨。

保证金比例是交易所正在收取的**普通月份**投机底数（非交割月里最低的一档），不是合约文本里常常印着的 5% 规则下限，也不是期货公司保证金。期货公司通常在交易所比例上再加一截。交割月（当前多为 10 月合约）常见 15% 或 20%，部分近月也临时高于下表。页面不按合约月份切换，格子旁边注明「交易所最低，近月可能更高」。

## 本地运行

只需 Python 3.11+ 标准库。在 `commodity/` 目录下执行（脚本按自身位置写 `data/`）：

```bash
python3 scripts/test_roll.py
python3 scripts/test_specs.py
python3 scripts/fetch_basis.py --rebuild-history   # 拉近三年日K并拼接，较慢
python3 scripts/fetch_basis.py                     # 只刷新快照并追加当天
python3 -m http.server 8741
```

打开 http://127.0.0.1:8741/ 。从仓库根目录开静态服务时，页面在 http://127.0.0.1:8741/commodity/ 。`--only m,rb` 只调试部分品种，结果写到 `data/debug.json`，不覆盖站点快照。

## 更新频率

仓库根目录的 `.github/workflows/update-commodity-basis.yml`

- 定时：`0 8 * * 1-5`（UTC）= 北京时间周一至周五 16:00，每日一次
- 页面右上角「手动刷新」打开 [Update commodity basis](https://github.com/heber/cffex-basis/actions/workflows/update-commodity-basis.yml)。静态站不放令牌；需要仓库写入权限，并在该页点 **Run workflow**
- 也可在 Actions 页手动 `workflow_dispatch`
- 与股指工作流共用并发组 `update-basis`，提交前 `git pull --rebase`，避免和根目录的 CFFEX 更新互相推掉
- 默认只拉最新报价并追加库存；全量重拉加 `--rebuild-history`
- 只提交 `commodity/data/latest.json` 和 `commodity/data/history/`。页面上的行情日和生成时间仍读 `data/latest.json` 的 `as_of` / `generated_at`，工作流提交并发布后刷新本页才变

行情接口（均带 `Referer: https://finance.sina.com.cn`）：

- 快照：`https://hq.sinajs.cn/list=nf_M2701,...`
- 日 K：`InnerFuturesNewService.getDailyKLine`（字段 `s` 结算、`v` 成交、`p` 持仓）

## 为什么不能照搬股指

商品没有分红。曲线是仓储、资金成本和便利收益的结果，库存松了就会从贴水翻成升水税。交割月有限仓和仓单，个人客户往往不能把近月持有到最后交易日，纸面价差不一定成交得了。

远月便宜也可能是「看空远期」（供给扩张、需求见顶），不完全是现货紧缺的便利收益。铁矿还要区分品牌和干湿吨。豆粕、油脂、苹果的斜率里混着季节。黄金这类好储存的品种，持有成本下升水才是常态。

所以这里把年化贴水当成**可比较的曲线状态**，并给出它在近 3 年里的位置。近月腿是离交割最近的未到期合约，不是现金现货。它不是股指那种分红调整后的结构性折价，也不能当成稳定股息。

## 免责声明

仅供研究参考，不构成投资建议。行情来自新浪财经公开接口，可能延迟或缺失。到期日未逐日剔除法定节假日。最低保证金是交易所普通月份的静态下限，期货公司实际收取通常更高，近交割月也可能上调。

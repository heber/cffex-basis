# 中国股指期货贴水跟踪（分红矫正）

跟踪中金所股指期货 **IH（上证50）、IF（沪深300）、IC（中证500）、IM（中证1000）** 四个活跃合约（当月、次月、当季、下季）的贴水/升水，并对期内分红做矫正后再年化。

**在线页面：** https://zaviichen.github.io/cffex-basis/

静态站托管在 GitHub Pages。行情不由 Pages 上的常驻服务拉取，而是由 GitHub Action 运行 `scripts/fetch_basis.py`，把结果写入 `data/latest.json`。

## 为什么要矫正分红？

价格指数在成分股除息时自然回落，期货定价已隐含期内分红。直接用 `(现货 − 期货) / 现货` 年化会把「分红」误当成「贴水」。

```
原始基差   = 现货 − 期货                 （正 = 贴水，负 = 升水）
矫正基差   = 原始基差 − 期内分红点数
年化贴水率 = 矫正基差 / 现货 × 天数因子 / 剩余自然日
```

年化只用自然日 **365**：矫正基差 / 现货 × 365 / 剩余自然日。不扣无风险利率，也不用 252 日。页面用红色标出「未扣分红的原始年化」，避免把分红季的近月贴水看成纯基差。

## 贴水分位

同一品种、同一期限（当月 / 次月 / 当季 / 下季）里，把**当前** `corr_ann_365` 放到历史分布中：

```
贴水分位 = 样本中 corr_ann_365 ≤ 当前值的个数 / N × 100%
```

范围 0–100%。**分位越高，当前越贴水**（期货比这段历史里更多的日子更便宜）。分位越低，表示当前更贵（贴水更浅或升水）。

- **展示窗口：** 近 3 年。样本是行情日往前 3 个日历年的交易日，**不含行情日当天**。例如行情日 2026-10-09 的样本是 2023-10-09 至 2026-10-08。
- **N：** 窗口内该期限实际有期货收盘价的交易日数。页面格子只写百分比（如 `72%`），样本不足为「—」；N 在悬停提示里，不写在格子里。少于 30 日不显示分位。

## 指数点位分位

同一品种、同一近 3 年日历窗口里，把**当日指数点位**放到历史指数收盘里：

```
指数点位分位 = 样本中指数收盘 ≤ 当日现货的个数 / N × 100%
```

范围 0–100%。**分位越高，指数越接近这段窗口的历史高位**。这是点位，不是贴水。分位越低，指数越接近窗口低位。

- **窗口：** 与贴水分位相同（行情日往前 3 个日历年，不含行情日当天）。
- **样本：** `data/history/series.json` 里已经存着每日指数收盘（每行的 `spot`）。同一交易日在多个期限里只计一次。某个期限缺期货收盘时，只要别的期限存了指数收盘，这一天仍计入指数样本，所以 N 可以和当月贴水样本数不同。
- **展示：** 每个品种一张卡片、一张表。列名和卡片标签仍是「贴水分位」「指数点位分位」，格子里只写百分比（如 `62%`）。少于 30 日显示「—」。改股息率不会改变这个分位。

## 历史库存

- **库存更长：** `data/history/series.json` 保存新浪日 K 可得的全部交易日（IH/IF/IC 约从 2018-10 起，IM 从 2022-07 上市起）。页面上的贴水分位和指数点位分位都只用其中近 3 年，四个品种的窗口才可比。
- **价格：** 期货与指数的日收盘价。指数点位直接用行里的 `spot`，不再另拉一套指数序列。股息率用仓库里的默认常数和同一套季节性模型，不是事后真实分红。
- **每日更新：** 工作日 16:00（北京时间）的 Action 把当日行情日的收盘追加进库存；同一天再跑会覆盖该日。全量重拉：

```bash
python3 scripts/fetch_basis.py --rebuild-history
```

当月在到期周剩余自然日很少，年化会被放大，贴水分位容易偏高。这是年化口径本身的特性。页面改股息率后，浏览器用同一库存重算贴水分位；指数点位分位不随股息率变化。

## 期内分红

```
期内分红点数 = 现货 × 年化股息率 × 剩余期限内季节性权重之和
```

季节性按 A 股分红节奏：5–7 月为高峰，其余月份权重大幅更低，权重归一化后按日比例摊进 `(今天, 到期日]`。

默认股息率（估算，可在页面上改，浏览器内重算，不改快照里的价格）：

| 品种 | 指数 | 默认股息率 | 乘数 |
|------|------|------------|------|
| IH | 上证50 `sh000016` | 2.3% | 300 |
| IF | 沪深300 `sh000300` | 2.1% | 300 |
| IC | 中证500 `sh000905` | 1.05% | 200 |
| IM | 中证1000 `sh000852` | 0.92% | 200 |

这不是券商成分股逐笔预测。

## 合约与行情

- **期货代码：** 新浪 `CFF_RE_{CODE}`（例如 `CFF_RE_IF2610`），请求带 `Referer: https://finance.sina.com.cn`
- **到期日：** 合约月份第三个周五
- **活跃合约：** 到期日 ≥ 今天的月份里，取当月、次月，再从其后取最近两个季月（3/6/9/12）作为当季、下季
- **合约市值** = 最新价 × 乘数
- **持仓名义市值** = 持仓量 × 最新价 × 乘数（仍写入快照，页面不展示）
- 周末和节假日沿用最近交易日收盘价

## 更新频率

`.github/workflows/update-basis.yml`：

- 定时：`0 8 * * 1-5`（UTC）= 北京时间周一至周五 16:00，每日一次
- 也可在 Actions 页手动 `workflow_dispatch`
- 脚本每次写入新的时间戳；`data/latest.json` 或 `data/history/` 有变化才提交
- 每次运行把行情日收盘追加进 `data/history/series.json`（已有日期覆盖）

本地手动刷新快照（仅标准库）：

```bash
python3 scripts/fetch_basis.py
```

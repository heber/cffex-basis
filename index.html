为什么简单贴水计算器是错的？

价格指数在成分股除息时自然回落，期货定价已隐含期内分红。 直接用 (现货 − 期货) / 现货 年化，会把「分红」误当成「贴水」。 必须用 矫正基差 = 原始基差 − 期内分红点数 再年化。 页面同时展示「未扣分红的原始年化」并以红色标注，提醒易误导。

贴水（现货 > 期货）绿 升水（现货 < 期货）红 年化贴水率正值 = 期货相对便宜（贴水） 贴水分位越高 = 当前比近 3 年同期限更贴水 指数点位分位越高 = 指数更接近近 3 年高位（不是贴水）

参数控制

现货与期货价格来自仓库里的 data/latest.json（工作日 16:00 北京时间由 GitHub Action 更新一次）。 页头「手动刷新」打开该工作流页面，不会在浏览器里直接拉行情；「重新加载」只重新读取已提交的快照。 修改股息率后，页面用同一季节性分红模型在浏览器里重算矫正基差、年化贴水（自然日 365）和贴水分位，不再请求行情服务器。指数点位分位只看指数收盘，不随股息率变化。 历史价格来自 data/history/series.json。 默认股息率：IH 2.3%、IF 2.1%、IC 1.05%、IM 0.92%（估算，5–7 月分红高峰）。

方法论与免责声明

  • 原始基差 = 现货 − 期货（正 = 贴水，负 = 升水）
  • 期内分红点数 = 现货 × 年化股息率 × 剩余期限内季节性权重之和（5–7 月高峰，按日比例）
  • 矫正基差 = 原始基差 − 期内分红点数
  • 年化贴水率 = 矫正基差 / 现货 × 365 / 剩余自然日（只用自然日 365，不含无风险利率，不用 252 日）
  • 贴水分位：同一品种、同一期限（当月 / 次月 / 当季 / 下季）里，分红矫正年化贴水小于等于当前值的交易日占比（0–100%）。分位越高，当前越贴水（比这段历史里更多的日子更便宜）；分位越低，当前越贵（贴水更浅或升水）。样本是行情日往前 3 个日历年，不含行情日当天。少于 30 个交易日不显示分位。
  • 指数点位分位：同一近 3 年窗口内，指数收盘小于等于当日现货的交易日占比（0–100%）。分位越高，指数越接近这段窗口的历史高位；分位越低，越接近窗口低位。这是指数点位，不是贴水。样本与贴水分位同一日历回看（行情日往前 3 个日历年，不含行情日当天），取库存里各期限按交易日去重后的指数收盘，所以 N 可以和某一期限的贴水样本数不同。少于 30 个交易日不显示。
  • 历史库存：新浪期货日 K 与指数日 K 的收盘价，自接口可得日起（IH/IF/IC 约 2018-10，IM 自 2022-07 上市），存在 data/history/series.json。贴水分位和指数点位分位都只用其中近 3 年。每个交易日 16:00（北京时间）的 Action 追加当日，同一天重复运行会覆盖。股息率用默认常数和同一季节性模型，不是事后真实分红。当月到期周剩余日很短，年化会被放大，贴水分位容易偏高。
  • 各品种库存起点与当月样本数见快照里的 history_meta。
  • 合约市值 = 最新价 × 乘数（IH/IF = 300，IC/IM = 200）
  • 到期日 = 合约月份第三个周五；活跃合约 = 当月 / 次月 / 当季 / 下季
  • 原始年化未扣分红，近月在分红季会明显偏高，容易误导
